# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of ClientFlow seriously. If you discover a security vulnerability, please do NOT create a public issue on GitHub.

Instead, please send an email directly to the maintainer:
- **Email:** `kenenisab05@gmail.com`
- **Subject:** `[SECURITY] ClientFlow Vulnerability Report`

### What to include:
- A clear description of the vulnerability
- Steps to reproduce or proof-of-concept
- Any potential impact on users or data

We will acknowledge receipt within 48 hours and work on a fix as quickly as possible.
